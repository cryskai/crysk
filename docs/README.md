# docs/

User documentation lives at **<https://crysk.dev/docs>** (index for agents: <https://crysk.dev/llms.txt>).
This folder documents how Crysk is built and operated, not how to use it.

## What is here today

| Path | What it is |
| --- | --- |
| `release-runbook.md`, `sandbox.md` | Operations: how a release is cut, and the sandbox repository used for live runs. |
| `multi-runtime-model-diversity-design.md` | Design: how reviews run on more than one model runtime. |
| `research/` | Dated research notes. A record of what was learned then, not current truth. |
| `history/` | Dated plans and roadmaps that were finished or replaced. Not current truth. |
| `benchmarks/` | JSON fixtures that tests read. Do not move or rename them without the tests. |
| `github-actions.md`, `configuration.md` | The engine's longer CI and configuration guides, kept because tests, skills and links already posted on pull requests point at their sections and anchors. The site is the source where they differ. |

Planned: `architecture/` and `operations/` folders will group the design and operations files. Nothing moves yet.
